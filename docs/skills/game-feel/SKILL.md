# Skill: Game Feel & Animation Guidelines

## เป้าหมาย
ประสบการณ์การเล่นต้องลื่นไหล 60 FPS ให้ความรู้สึกเหมือนกำลังนั่งล้อมโต๊ะเล่นการ์ดเกมจริง (เช่น Board Game Arena / Uno Online) ไม่ใช่การกรอกแบบฟอร์มควิซ

## แอนิเมชันและเอฟเฟกต์
- **Hand of Cards (มือไพ่)**: พัดเป็นมุม arc (-18° ถึง +18°) อยู่ส่วนล่างของจอ
- **Hover**: ยกไพ่ขึ้น 16px พร้อมเพิ่มเงาเลนส์ขยายสำหรับอ่านรายละเอียด
- **Play Card**: ไพ่บินพุ่งเข้าสู่โซนกลางโต๊ะ ระยะเวลา 420ms ด้วย easing `cubic-bezier(0.2, 0.8, 0.2, 1)`
- **Answer Feedback**:
  - ผิด: สั่นการ์ด 300ms + ขอบแดงกระพริบ + เสียง fail
  - ถูก: ขอบทองสว่างเรืองแสง + particles + เสียงกระดิ่ง/เหรียญ
- **Countdown**: วงแหวนนับถอยหลังรอบนาฬิกา (Timer Ring) โดยใน 10 วินาทีสุดท้าย ตัวเลขนับถอยหลังจะสั่นพร้อมเสียงติ๊กเตือน
